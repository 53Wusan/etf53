# 53 的杠杆 ETF 策略台

**恐惧时分批，贪婪时克制。**

这是一个供个人每日查看操作计划、跟踪模拟账户和核对交易的策略台。它把收盘行情转换为规则明确的下一交易日计划，帮助减少临时追涨、恐慌卖出和频繁改主意。

打开首页，先回答「今天有没有操作」；进入账户，查看现金、持仓、盈亏，以及模拟成交是否符合此前的计划。系统不连接券商，不自动下单。

## 每天怎么用

1. **每日操作**：首先查看下一交易日的模拟买卖计划；无操作也是计划的一部分。行情过期或方案日期不齐时暂停展示操作。
2. **市场状态**：快速查看中期趋势、短期状态、波动与急跌警报。中期上行可以与单日急跌同时出现；新闻和重要日程按需展开。
3. **指数看板**：查看14只ETF的收盘价格、交易指数与历史曲线。默认关注的9只参与组合研究，其他品种供观察。
4. **账户与对账**：跟踪独立模拟账户，核对每日计划与模拟成交，区分历史回放与实际留档记录。
5. **保留方案与计算说明**：需要时查看候选方案、回测与规则；计算说明先提供直白解释，再展开公式。

## 如何理解结果

交易指数越低越偏恐惧，越高越偏贪婪。当前冻结模型的图表刻度为−50～+50，直接与方案门槛比较即可；分数不是涨跌概率或收益率。达到分数门槛也不一定交易，还需满足仓位、现金、间隔和退出条件。

市场风险卡独立检查大盘、半导体单日及五日跌幅和VIX，不参与当前策略下单条件。风险等级是规则警报，尚未验证为预测模型。模拟收益与回测不保证未来表现，实际成交价格与费用也可能不同。

## 网站与自动更新

- [打开策略台](https://53wusan.github.io/etf53/)
- [查看自动更新结果](https://github.com/53Wusan/etf53/actions/workflows/daily-desk.yml)

每日收盘后由 GitHub Actions 获取完整日线、计算指数与模拟计划，随后生成静态网页并发布到 GitHub Pages。定时安排为 UTC 23:47 周一至周五（北京时间周二至周六07:47）；GitHub 调度可能延迟。页面标明数据日期，行情过期时暂停提供操作计划。

网页无需登录。行情、策略及模拟账户视图公开可读；券商账号、凭证和内部配置不会发布。内部账户状态使用 GitHub Secret 加密保存，自动任务使用的密码不是网站登录密码。

## 部署与维护

1. 在仓库 Actions Secrets 配置 `DESK_PASSWORD`，用于读取既有加密账户状态；不要将密码写入代码。
2. 将 Pages 发布来源设置为 GitHub Actions。
3. 推送到 `main`，或在 Actions 手动运行 `Daily ETF desk`。
4. 等待更新与发布两项任务成功，再核对网页数据日期、账户日期及各品种历史曲线。

本项目以已冻结规则运行，不自动优化参数。费用、份额和模拟成交假设以页面说明为准，实际交易独立核对。
