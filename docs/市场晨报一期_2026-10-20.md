# 市场晨报一期

日期：2026-10-20，北京时间。

目标：每天先了解市场环境，再看持仓盈亏。沿用现有GitHub日更流程，不调用AI、不新增密钥或付费API。

## 页面与含义

首页最上方显示三项独立观察：中期趋势、短期状态、波动与急跌风险。它们描述已经发生的收盘状态，不是下一日涨跌预测，也没有把人为打分解释成上涨概率。

中期趋势按SPY、QQQ、IWM相对50/200日均线判断：至少两个同时在两条均线上方为中期上行，同时在下方为中期下行，其余为震荡分化。短期按三个市场近5日均值达到±1%且至少两个同方向，分别记回升或回撤。

风险偏高的观察线为：VIX≥25、VIX近5日升幅≥25%、QQQ近5日跌幅≥5%、SPY近5日跌幅≥3%，任一触发。风险很高为：VIX≥35、QQQ近5日跌幅≥10%、SPY近5日跌幅≥6%。VIX读取失败则不判为常态。这些是首版固定规则，未验证预测能力；“常态”不意味着不会亏损。

QQQ近5日跌幅≥3%或SOXX跌幅≥5%时，另记科技回撤较大。这不是新闻归因，也没有断言科技板块下跌必然扩散。

## 数据来源与质量

- 市场代理：SPY、QQQ、IWM、RSP、SOXX；背景代理：GLD、UUP及Yahoo的^TNX收益率报价。日线优先读取项目已有Yahoo提供器，ETF可尝试StockAnalysis备用来源。来源不完整时不补旧值。
- 当前完整交易日沿用项目的美股交易日历及收盘后缓冲。滤去未完成日期，要求至少253条完整历史、近253日无缺失、价格有限且为正。非杠杆ETF复权单日异常超过50%时拒绝使用。
- VIX：[Cboe历史日线](https://cdn.cboe.com/api/global/us_indices/daily_prices/VIX_History.csv)。按NYSE交易日日历对齐，排除来源中的休市日期记录，再检查应有交易日是否到齐；分位只使用当前值之前的252个交易日。
- RSP与SPY的20日收益差为等权相对强度代理，不是实际上涨家数或成分股广度。UUP、GLD也分别是美元和黄金的ETF代理。
- ^TNX收盘值按收益率百分数展示，5日变化按“百分点×100”转换为基点，不把收益率变动率当债券价格回报。
- 页面把收盘行情日期与新闻核查时间分别展示。超出下一交易日收盘30分钟后，隐藏当前趋势和风险结论并提醒待更新，旧数字保留日期用于核对。

## 日历与新闻

- [美联储会议日历](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)：提取会议最后一日，日期不等同已核验发布时刻，不自行假设14:00。
- [BEA发布日历](https://www.bea.gov/news/schedule)：显示GDP、个人收入支出等官方日期。保留原文标题，PCE对应个人收入与支出发布。
- [BLS官方ICS](https://www.bls.gov/schedule/news_release/bls.ics)：成功读取时按原始时区转换CPI、PPI、就业等事件。当前本地试读为403，明确标记日历不完整，不绕过访问限制，不推断“没有重要事件”。
- 新闻来源为[WSJ Markets RSS](https://feeds.content.dowjones.io/public/rss/RSSMarketsMain)、[MarketWatch RSS](https://feeds.content.dowjones.io/public/rss/mw_topstories)、[美联储政策RSS](https://www.federalreserve.gov/feeds/press_monetary.xml)。仅保存原标题、链接、时间与关键词主题标签，不抓全文、不生成利好利空判断。部分原文可能需要订阅。
- 近72小时内按主题过滤，优先选大盘/政策、经济和科技标题，排除固定的Roundup/Market Talk汇编和明显个人理财题，再去重并按时间排列，最多8条，每来源最多4条；不是AI评选的“全球最重要八件事”。剔除无时区、明显未来和无有效HTTPS链接的条目。
- 日历只覆盖已接入官方来源未来14天。财报日历、突发地缘事件和所有经济指标尚未完整覆盖，不能依赖空列表判断事件风险为零。

## 自动运行和隔离

GitHub `Daily ETF desk` 在现有账户计算完成后增加独立晨报步骤。宏观服务来源失败时仍输出部分可用快照和源状态；该步骤异常时保留现网交易流程，过期的晨报不会继续显示为当前结论。行情、新闻和日历逐项标记，不能把一个来源成功当成整体完整。

每次生成保存 `research/output/market_brief/latest.json` 与按实际生成时间命名的captures文件，再导出为 `data/market-brief.json`。API提供只读 `/api/market/brief`。页面每5分钟或切回页面时复用现有快照刷新机制。

本轮没有修改现网贪婪恐惧指数、交易引擎或观察版本锁定的计算文件。宏观观察只供阅读与复盘，若将来要进入买卖规则，需另做同口径回测。
