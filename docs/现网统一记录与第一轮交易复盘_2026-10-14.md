# 现网统一记录与第一轮交易复盘

日期：2026-10-14，北京时间。

## 本轮结论

现网方案②已经可以作为固定研究基准，但不能称为已经证明的长期投资优势。它在多种历史起点下通常承受比40/30/30持有组合更小的回撤，也在明显上涨的窗口牺牲了大量收益。不同起点会改变排名；近期较小回撤不能外推成风险上限。

本轮完成运行记录统一、现网账户同本金对照和第一轮历史交易归因。没有改变买卖规则、指标参数或持仓预算。下一轮先验证入口与资金占用的机制，再决定是否值得建立候选。

## 唯一运行口径

- 日常运行由 GitHub Actions `Daily ETF desk` 完成，站点 https://53wusan.github.io/etf53/ 展示发布的快照。
- 主账户为方案②，2026-10-06启用，初始45,000美元。每笔初始本金5%，最多4笔/只、5只同时持有；账户内不另留固定现金底线。每笔预算固定，不随净值复利放大。
- 九只交易品种：TQQQ、FAS、GDXU、CURE、DFEN、TECL、UPRO、EDC、UGL。SOXL是对照的一部分，不能误写成当前九只之一。
- 指数≤0考虑买入；仍在买入区、较上笔开盘买价跌5%、间隔至少3自然日才加仓。指数≥20或持仓盈利50%启动保护，之后回撤10%逐笔卖出；持仓到期90自然日也退出。具体顺序仍由未改动的执行引擎决定。
- 旧版各10万美元、20日对照实验的聊天自动任务已经删除；旧账本保留，不能改写成新试验。

现网规则来源：冻结配置 `research/configs/baseline_review_20261014.json`，读取时远端提交 `6c8b76a231979e7e9a64da3616442af2b1df20be`，公开账户及catalog行情日2026-10-12。它们确认当前设置；本地较旧的account配置不作为现网启用日依据。

## 每日记录的新增能力

新观察版本 `rank2-account-observation-v1` 单独保存于 `research/output/forward_data/account_observation/`，与失效的 `no_yinn_paper_v1` 试验分开。

1. 首次启动记录实际捕获时间、当前策略与代码哈希；之后规则或计算实现变化将阻止该版本继续追加，必须显式建立新版本。
2. 每个行情日保存现金、持仓、资产、当日模拟成交、次日计划、来源快照哈希及前一记录哈希；同日重跑保留原时间，数据变化拒绝覆盖。
3. 检查行情日已收盘、下一开盘日期正确，并记录意向是否早于下一开盘。
4. GitHub Pages部署成功后另存发布回执，绑定当日记录哈希；重复发布保留首次成功回执。下次更新读取这一证明，只有计算与发布都早于下一开盘才标为及时前瞻计划。回执捕获晚于实际发布，是保守的确认时间。
5. 当连续的上一日计划存在时，核对本日成交品种、方向与原因；模拟开盘价格和数量允许与昨日估算不同。没有及时发布证明时，即使成交吻合，也不算完整前瞻验证。
6. 标记遗漏日期、迟到计划、迟到发布、有成交但没有及时计划证明的日期。首次登记以前的账户历史属于回放，不能宣称完整前瞻性。
7. 账户页展示运行链接、版本、留档统计、资产曲线、同本金40/30/30对照及逐品种盈亏贡献。更新时间超过下一交易日收盘30分钟时提醒核查任务。

运行页面只证明最近成功发布的快照；如果计算或发布失败，静态站点无法自行知道尚未发布的失败细节，需结合GitHub运行结果。GitHub记录是调度与发布状态的权威来源。

GDXU约占总净利润41.2%；最大的5笔已平仓利润占全部已实现净利润33.1%。这揭示集中度，不能据此直接删掉其他品种或宣称GDXU未来仍领先。

卖出原因：82笔“上涨后回撤”，已实现利润23,841.07美元；47笔“持仓到期退出”，已实现利润32,856.40美元。到期卖出的批次持有中位数74天，是因为到期按整只持仓的首次买入时间计算，后续加仓批次可能不足90天。

买入后固定持有20交易日的描述性结果：首笔68个完整窗口，净收益中位数4.89%、正收益比例66.2%；加仓65个完整窗口，中位数11.01%、正收益比例70.8%。加仓后的20日内最差收盘相对买入价变化中位数为−10.29%，首笔为−4.42%。净收益按假设期末卖出并收取费用计算，不等于实际策略该日已经兑现。

这些事件窗口重叠、品种与行情状态不同，既不能当成独立样本，也不能把加仓组更高收益当成加仓有因果优势。尾部不足完整窗口保留为空。另有5/60日路径与卖出后5/20日变化保存在逐笔文件中；最差收盘变化不是盘中最大损失。

近期有793次候选因资金或同时持仓名额限制未买入，这是逐日候选次数，不是793个互相独立机会。现有计数没有区分资金不足与名额不足，本轮不猜测两者比例。平均仓位31.2%也包含固定初始本金分笔与账户增长的影响，不能直接推导“加大仓位一定更好”。

## 下一轮已明确的验证顺序

1. 先拆分名额阻断、现金阻断与固定分笔造成的敞口变化，并与同九品种简单持有、简单趋势入口比较，区分品种选择与择时。
2. 对比首笔恐惧直接买入与当时可识别的恢复确认入口，保持其余执行规则、预算、费用相同；检查减少接跌的同时是否错过快速反弹。
3. 检查卖出后的固定期限路径与持仓期盈利回吐，优先解释到期退出与回撤保护的差异，再决定是否调整退出方式。
4. 只有少量候选在多阶段、费用与执行延迟检查后有支持，才冻结候选进入新的并行观察。现网页面继续使用当前固定基准，不按短期排名自动换策略。

暂不扩大品种池、追求满仓或继续大规模扫参数。未来新品种/指标、真实最低佣金、整股限制、滑点、税和现金收益仍需独立核验。此前历史已经反复参与筛选，本次属于开发与诊断；20个交易日只验收运行链路，不能证明长期收益优势。
